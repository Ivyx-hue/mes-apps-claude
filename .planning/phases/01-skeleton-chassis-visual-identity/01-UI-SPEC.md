# Phase 1 — UI Design Contract

> Visual and interaction contract for the QHSE CESI Hub skeleton + visual identity. Generated by gsd-ui-researcher, awaiting owner sign-off on the four gate items in `## Owner Gate Decisions` before any HTML is written. Verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (single-file vanilla HTML+CSS+JS, no build, no framework — locked by PROJECT.md / INFRA-02) |
| Preset | not applicable |
| Component library | none — hand-rolled CSS components, `@layer reset, tokens, base, components, utilities` |
| Icon library | Lucide static SVG sprite (version-pinned `lucide@0.460.0`), inlined as `<symbol>` references — NOT the UMD runtime |
| Font | Google Fonts CSS2 — Fraunces (display) + Inter (body/UI) + JetBrains Mono (technical strings) |

**Single Google Fonts request** (with `preconnect` to `fonts.googleapis.com` AND `fonts.gstatic.com`):

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,400;9..144,600;9..144,700&family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap" rel="stylesheet">
```

**Why distinct from the QHSE Trainer (`/index.html` at repo root):** Trainer uses Bebas Neue + Space Mono + DM Sans on `#090908` with `#C8FF00` lime accent and a radial-dot grid texture — "Industrial Safety Terminal". The Hub must read as "editorial library / reading room": warm-dark surfaces, serif headlines, no grid texture, no neon. The IDENT-01 requirement is contract: side-by-side at `/` and `/qhse-cesi/`, the two apps must feel like the same owner ran two different projects, not a colour swap of one.

## Spacing Scale

T-shirt scale, modular base 4 px / 0.25 rem — **all values multiples of 4**. Spacing tokens consumed exclusively via CSS custom properties; no raw `1.5rem` in component CSS.

| Token | Value | Usage |
|-------|-------|-------|
| `--space-xs` | 4 px (0.25rem) | Icon inner gap, gap between `<time>` and date label |
| `--space-sm` | 8 px (0.5rem) | Inline label padding, badge inner padding, focus-ring offset distance |
| `--space-md` | 16 px (1rem) | Default vertical rhythm between paragraphs, nav item horizontal padding, card inner padding (mobile) |
| `--space-lg` | 24 px (1.5rem) | Section heading → first child gap, card inner padding (desktop) |
| `--space-xl` | 32 px (2rem) | Sub-section breaks inside Découverte, nav-to-content gap on mobile |
| `--space-2xl` | 48 px (3rem) | Major section breaks (`#accueil` → `#decouverte` → `#biblio`) on mobile |
| `--space-3xl` | 64 px (4rem) | Same section breaks on desktop; top of `<main>` to first content; footer top-padding |

**Exceptions:**
- Burger-menu touch target: minimum 44 × 44 px (WCAG 2.5.5 / Apple HIG floor). Visual icon is 24 × 24 inside a 44 × 44 hit area — pad with `--space-sm` × 2 + icon, do not shrink the touch target to fit the spacing scale.
- Skip-link is positioned with explicit `top: 0.5rem; left: 0.5rem` when focused — 8 px is the floor.
- Sticky header `height: 64px` (`4rem`) is itself a spacing landmark — referenced by `--header-h` and reused in `scroll-padding-top` + `scroll-margin-top` so the offset is single-source.

## Typography

Three families, fluid sizes via `clamp()`, four roles. Body weight is `400` regular; subtle emphasis uses `500`; headings use `600`. **No font-size lives outside this table.** Components reference `--step-*` custom properties only.

**Families:**

```css
--font-serif: 'Fraunces', Georgia, 'Times New Roman', ui-serif, serif;
--font-sans:  'Inter', system-ui, -apple-system, 'Segoe UI', sans-serif;
--font-mono:  'JetBrains Mono', ui-monospace, 'SF Mono', Menlo, Consolas, monospace;
```

**Variable axes used:**
- Fraunces `opsz` 9..144 (optical sizing — small captions use lower `opsz`, large display headlines use higher); weights 400 / 600 / 700.
- Inter weights 400 / 500 / 600 / 700.
- JetBrains Mono weights 400 / 500.

**Type scale (fluid, viewport-responsive — no media-query breakpoints required for type):**

| Role | Token | Family | Weight | Size | Line-Height | Notes |
|------|-------|--------|--------|------|-------------|-------|
| **Display (h1, hero)** | `--step-5` | Fraunces (`opsz` auto) | 600 | `clamp(2.25rem, 4vw + 1rem, 4rem)` — 36 → 64 px | 1.1 | `text-wrap: balance`. Used once per page (`#accueil` h1). Letter-spacing `-0.01em`. |
| **Heading 2 (section)** | `--step-4` | Fraunces | 600 | `clamp(1.75rem, 2vw + 1rem, 2.5rem)` — 28 → 40 px | 1.15 | `text-wrap: balance`. Carries the section-accent underline (gate decision 4). |
| **Heading 3 (subsection)** | `--step-3` | Fraunces | 600 | `clamp(1.25rem, 1vw + 0.9rem, 1.5rem)` — 20 → 24 px | 1.2 | No underline. |
| **Body large (lead paragraph)** | `--step-2` | Inter | 400 | `clamp(1.0625rem, 0.4vw + 1rem, 1.125rem)` — 17 → 18 px | 1.65 | Used once: first paragraph of `#accueil` and lead pitch of `#decouverte` (Phase 2). |
| **Body** | `--step-1` | Inter | 400 | `16px` (`1rem`) | 1.6 | The single body size for V1. `text-wrap: pretty`. |
| **Label / meta / nav item** | `--step-0` | Inter | 500 | `0.875rem` (14 px) | 1.4 | Nav links, footer text, badge labels. Letter-spacing `0.01em`. |
| **Caption / eyebrow** | `--step--1` | Inter | 500 | `0.75rem` (12 px) | 1.4 | Section eyebrow ("01 / DÉCOUVERTE"), `lastChecked` date in Phase 3. `text-transform: uppercase`, letter-spacing `0.08em`. |
| **Mono (technical strings)** | n/a | JetBrains Mono | 400 | `0.9em` (relative to surrounding text) | inherited | RNCP codes, ISO numbers, ISO dates, URLs in print. Never used for body. |

**Measure (line length):** `--measure: 68ch` — applied to `p`, `li`, `blockquote` in `@layer base`. Headlines opt out (full width up to `--container-max`).

**Letter-spacing:**
- Display + h2: `-0.01em` (sucked-in editorial feel)
- All other roles: `0` (default)
- Eyebrow / caption: `0.08em` (open, archival)

**Anti-pattern guard:** the QHSE Trainer uses `letter-spacing: 0.18em` on Bebas Neue for an industrial look. The Hub explicitly does NOT use letter-spacing > `0.08em` anywhere. If a designer reaches for it, redirect to Fraunces `opsz`.

Dark wins by default via `color-scheme: dark light` on `:root` and `<meta name="color-scheme" content="dark light">`. **No `#000` background, anywhere.** All tokens checked against WCAG 2.1 SC 1.4.3 (4.5:1 body, 3:1 large).

### 60 / 30 / 10 split

- **60 % dominant — `--bg-1` (`#1a1814` warm dark)** — `<body>` background, fills the viewport, primary reading surface.
- **30 % secondary — `--bg-2` (`#221f1a`)** — sticky header, Phase 3 card surfaces, mini-TOC, footer background.
- **10 % accent — `--accent` (`#c9a96e`)** — strictly limited per gate decision 4.

### Accent reserved-for list (canonical — DO NOT widen without re-opening gate decision 4)

The accent (`#c9a96e`) appears on, and only on:

1. Inline links (`<a>` outside of nav and outside of cards) — colour + 1 px underline; 2 px underline on `:hover` / `:focus-visible`.
2. The active top-nav item — `color: var(--accent)` + an accent-coloured underline indicator 2 px tall, positioned via `::after`; non-active items remain `--ink-2`.
3. Section `<h2>` heading underline — 2 px solid `--accent`, 0.5em below the headline baseline, width `2.5em` (a quoted-rule effect, NOT full-width).
4. (Phase 3 only) Category badges + the small dot in the `lastChecked` rendering.

The accent does NOT appear on: body text, eyebrow labels, h1 / h3 / h4, paragraph emphasis, footer copy, the burger icon (stays `--ink-1`), the skip-link (uses `--focus-ring` for visibility against any background).

### Contrast contract (IDENT-05 — enforce before merge)

- Body text (`--ink-1` on `--bg-1`): ≥ 4.5:1 — measured 12.5:1 dark, 14.2:1 light.
- Muted text (`--ink-2` on `--bg-1`): ≥ 4.5:1 — measured 5.6:1 dark, 7.8:1 light.
- Accent on background (`--accent` on `--bg-1`): ≥ 4.5:1 for body, ≥ 3:1 for large — measured 7.2:1 dark, 4.9:1 light.
- Focus ring (`--focus-ring` against `--bg-1` AND against `--accent` AND against `--bg-2`): ≥ 3:1 in all three pairings.
- **No pure `#000` background anywhere.** No `oklch(0%...)`. The dark token floor is `oklch(15% ...)`.

### Destructive

V1 has no destructive actions (read-only Découverte + Biblio). The `--alert` token is reserved for `lastChecked > 180 d` link-staleness signalling in Phase 3 — it is NOT a destructive-action red. If a destructive action ever lands (V2+), a new token (`--destructive`) must be declared; do NOT repurpose `--alert`.

## Radius

Three steps. Editorial register skews softer than the Trainer's sharp industrial edges, but stops short of pill-shaped. **No `border-radius: 50%` except for the optional avatar slot (not used in V1).**

| Token | Value | Usage |
|-------|-------|-------|
| `--radius-sm` | `4px` (0.25rem) | Badges (Phase 3), `<kbd>`, focus-ring rendering on inputs (none in V1), small interactive pills |
| `--radius-md` | `8px` (0.5rem) | Default — Phase 3 cards, mini-TOC, nav hover backdrop, code blocks |
| `--radius-lg` | `16px` (1rem) | Reserved — Phase 3 "featured / pinned" cards if priority-1 visual distinction is needed. NOT used in V1 chassis. |

## Borders / Dividers

Editorial register = flat surfaces + hairline rules, not shadow-elevation. Borders carry layout meaning; shadows are minimal.

- **Default border:** `1px solid var(--border-subtle)` — sticky header bottom, footer top, Phase 3 card outline, mini-TOC outline.
- **Section divider:** **none** between major sections (`#accueil` → `#decouverte` → `#biblio`). The vertical rhythm itself (`--space-3xl` gap) is the divider. The optional decorative element is a centred 1 px × 2 em horizontal rule using `--ink-3` at 40 % alpha — used at most twice on the page.
- **h2 underline (accent treatment):** 2 px solid `--accent`, NOT a border on the heading — implemented via `::after` so it does not interfere with `text-wrap: balance`. Width fixed at `2.5em`, left-aligned.
- **Focus ring:** 3 px solid `--focus-ring`, 2 px offset — outline, not border. Applied via `:focus-visible` only (never `:focus` — that fires for mouse too).

## Shadow / Elevation

**Minimal — editorial flat, not Material elevation.** The chassis ships exactly two shadow tokens; one is used only by the sticky header on scroll.

| Token | Value | Usage |
|-------|-------|-------|
| `--shadow-none` | `none` | Default state of Phase 3 cards and all surfaces. |
| `--shadow-sticky` | `0 1px 0 0 var(--border-subtle), 0 12px 24px -16px oklch(0% 0 0 / 0.45)` | Sticky header *only*, applied after a scroll threshold (`html:has(:not(:target)) header` baseline → see Interaction Contract). Provides depth cue without breaking the flat editorial feel. |

`box-shadow` on hover / card states is **explicitly avoided** — hover affordances come from border-colour shifts and underline thickness, not lift-shadows. (Anti-pattern flagged in PITFALLS.md performance traps: animating `box-shadow` causes mobile scroll jank.)

## Layout Grid

- **Container max-width:** `--container-max: 72rem` (1152 px). Centred via `margin-inline: auto`; horizontal padding `clamp(1rem, 4vw, 2rem)`.
- **Measure (line length for reading):** `--measure: 68ch`. Applied to `p`, `li`, `blockquote`, `dd` in `@layer base`. Headlines override (full container width). Phase 2 Découverte prose lives inside `--measure`; Phase 3 Biblio grids do not.
- **Breakpoint:** **one** breakpoint at `min-width: 48rem` (768 px) — locked by CHASSIS-07. Below 48 rem: single-column, burger menu, increased vertical rhythm. At/above 48 rem: horizontal nav, optional 2-column grid in Phase 3.
- **Header height:** `--header-h: 4rem` (64 px). Reused by `html { scroll-padding-top: var(--header-h); }` AND `section { scroll-margin-top: var(--header-h); }` — single source of truth.
- **Section scroll-offset:** `scroll-margin-top: var(--header-h)` on every `<section>` and on every `<h2>` inside `<section>` (belt-and-suspenders for iOS Safari quirks).
- **CSS Layer order:** `@layer reset, tokens, base, components, utilities;` — declared once at the top of `<style>`. Reset always loses to component styles.

## Component Contracts

The chassis ships exactly six components. Each is named, scoped, and contracted. No others are introduced in Phase 1.

### 1. Skip-link

```html
<a class="skip-link" href="#main">Aller au contenu principal</a>
```

- **First focusable element** in `<body>` — before `<header>`.
- Visually hidden by default (`clip-path: inset(50%)`, `position: absolute`, off-screen).
- On `:focus-visible`: snaps to `top: 0.5rem; left: 0.5rem`, becomes a small accent-bordered pill: `background: var(--bg-2)`, `color: var(--ink-1)`, `padding: var(--space-sm) var(--space-md)`, `border: 2px solid var(--accent)`, `border-radius: var(--radius-sm)`, `z-index: 1000` (above sticky header).
- Click / Enter scrolls to `#main` and moves focus into `<main>`.
- Copy: `Aller au contenu principal` (French, full sentence — owner is French; the Trainer used English; the Hub uses French throughout — see Copywriting Contract).

### 2. Sticky header / top nav

```html
<header role="banner">
  <a class="brand" href="#accueil">QHSE&nbsp;<em>CESI</em></a>
  <input type="checkbox" id="nav-toggle" class="nav-toggle" aria-label="Ouvrir le menu">
  <label for="nav-toggle" class="burger" aria-hidden="true">…</label>
  <nav aria-label="Navigation principale">
    <ul class="nav__list">
      <li><a href="#accueil" data-target="accueil">Accueil</a></li>
      <li><a href="#decouverte" data-target="decouverte">Découverte</a></li>
      <li><a href="#biblio" data-target="biblio">Biblio</a></li>
      <li hidden><a href="#outils" data-target="outils">Outils</a></li>
    </ul>
  </nav>
</header>
```

**Visual contract:**

- Height: `var(--header-h)` (64 px), full-width, `position: sticky; top: 0; z-index: 100`.
- Background: `color-mix(in oklch, var(--bg-2) 88%, transparent)` — 88 % `--bg-2` allowing the page beneath to bleed faintly. `backdrop-filter: blur(12px) saturate(120%)` for the frosted-glass effect; `@supports not (backdrop-filter: blur(1px))` fallback → opaque `--bg-2`.
- Bottom border: `1px solid var(--border-subtle)`.
- On scroll past 16 px (detected via `IntersectionObserver` on a sentinel `<div>` at the top of `<main>`, NOT a scroll listener), the header gains `--shadow-sticky`.
- Brand: Fraunces 600, `var(--step-1)`, letter-spacing `-0.01em`. The `<em>` (CESI) is `--accent`; the rest is `--ink-1`. No italic — `font-style: normal` override.

**Nav-link contract (desktop ≥ 768 px):**

- Inter 500, `var(--step-0)` (14 px), `var(--ink-2)` default.
- Horizontal padding `var(--space-md)`, vertical padding `var(--space-sm)`, gap between items `var(--space-sm)`.
- `:hover`: `color: var(--ink-1)`, background `var(--accent-soft)`, `border-radius: var(--radius-sm)`. No transform, no shadow.
- `:focus-visible`: 3 px `--focus-ring` outline, 2 px offset.
- **Active state** (matches scroll position via `IntersectionObserver` — V1 ships this even though it's listed as v1.1 in research, because the chassis already wires it for the burger menu and it's free): `color: var(--accent)` + a 2 px `--accent` underline indicator implemented via `::after` (positioned `bottom: -1px` against the header bottom-border).
- Active state is ALSO triggered by `:target` for direct-hit anchors (`#decouverte` in URL bar) for the no-JS fallback.

**Burger menu (≤ 767 px) — CSS-only via `:has()`:**

- Hidden checkbox `<input type="checkbox" id="nav-toggle">` paired with a 44 × 44 px `<label>.burger` (the hit target).
- `nav:has(#nav-toggle:checked) .nav__list { display: flex; ... }` → menu slides into view (full-width `position: fixed`, top: `var(--header-h)`, bottom: 0, background `--bg-1`, vertical link list, each link `var(--step-2)` 17 px for tap comfort).
- `nav:has(#nav-toggle:not(:checked)) .nav__list { display: none; }` — strict default-closed.
- **Burger MUST close synchronously before scroll fires** (PITFALL-8). Implementation: minimal JS — one delegated click listener on `.nav__list` that, before the browser's default anchor navigation runs, sets `document.getElementById('nav-toggle').checked = false`. Because the listener does NOT `preventDefault()`, the native anchor scroll fires after, with the menu already closed. ~5 lines.
- Burger icon: inline Lucide `menu` (24 × 24) when closed, Lucide `x` (24 × 24) when open — swap via `.nav-toggle:checked ~ .burger { background-image: url("data:image/svg+xml,..."); }` or via two stacked SVGs toggled by sibling-checked. Colour: always `--ink-1`, never `--accent`.
- Touch target: 44 × 44 px minimum (WCAG 2.5.5).
- `aria-label` on the checkbox (not the label) reads "Ouvrir le menu" / "Fermer le menu"; alternation handled by `aria-label` mirroring `:checked` state via a tiny JS effect OR by a screen-reader-only `<span class="sr-only">` swapped via `:has(:checked)`. The CSS-only path is preferred.

**Print:** `@media print { header { display: none; } }`.

### 3. Section heading pattern (`<h2>`)

```html
<section id="decouverte" aria-labelledby="h-decouverte">
  <p class="eyebrow">02 / DÉCOUVERTE</p>
  <h2 id="h-decouverte">La formation, en un survol</h2>
  ...
</section>
```

- **Eyebrow** above the h2: `--step--1` (12 px), Inter 500, `--ink-2`, uppercase, letter-spacing `0.08em`. Format: `"NN / TITRE"`. Margin-bottom `var(--space-sm)`.
- **h2:** Fraunces 600, `--step-4`, `--ink-1`, `text-wrap: balance`, letter-spacing `-0.01em`. Margin-bottom `var(--space-lg)`.
- **Underline indicator (accent treatment per gate decision 4):** `h2::after { content: ""; display: block; width: 2.5em; height: 2px; background: var(--accent); margin-top: var(--space-sm); }`. Single source of accent expression at the section level.
- `aria-labelledby` references the h2's `id` for landmark labelling.
- `scroll-margin-top: var(--header-h)` — guarantees the h2 lands below the sticky bar.

### 4. Section shells

Four `<section>` elements live inside `<main id="main">`:

| ID | Label | State in V1 | Phase wiring |
|----|-------|-------------|--------------|
| `#accueil` | Accueil | Single h1 + lead paragraph placeholder | Phase 2 fills lead copy |
| `#decouverte` | Découverte | Eyebrow + h2 placeholder, empty body | Phase 2 fills content |
| `#biblio` | Biblio | Eyebrow + h2 placeholder, empty mount point `<div id="biblio-grid"></div>` | Phase 3 renders cards into the mount point |

## Motion Contract

**Editorial register favours stillness.** Movement is minimal, never decorative, always purposeful.

| Motion | Default | Reduced-motion override |
|--------|---------|-------------------------|
| Anchor-link scroll | `html { scroll-behavior: smooth; }` (native, no polyfill) | `scroll-behavior: auto;` — instant jump |
| Section entrance on first render | `@starting-style` fades sections from `opacity: 0` to `opacity: 1` over 320 ms ease-out on `:first-of-type` mount (V2 — NOT shipped in Phase 1 chassis; reserved CSS skeleton may be present but commented). Phase 1 ships zero entrance animation. | n/a in V1 |
| Link underline thickness change (hover) | 80 ms ease-out transition on `text-decoration-thickness` | Transition duration `0.01ms !important` |
| Nav-item hover backdrop | 120 ms ease-out transition on `background-color` | Same override |
| Sticky-header shadow appearance (on scroll past 16 px) | 200 ms ease-out transition on `box-shadow` | Same override |
| Burger menu open/close | 0 ms (instant — CSS `display` toggle, NOT a slide animation). Justified by CHASSIS-03 "auto-closes synchronously when a link is clicked, before the scroll fires" — animated close would race the scroll. | n/a |
| Any other motion | Not allowed in V1. | n/a |

**`prefers-reduced-motion` block (CHASSIS-09, mandatory in `@layer reset`):**

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

This block must be present in the reset layer from the first commit.

## Print Stylesheet (CHASSIS-06)

```css
@media print {
  /* Hide chrome */
  header, .skip-link, .nav-toggle, .burger { display: none !important; }
  /* Force light, max-contrast surface */
  :root { color-scheme: light; }
  body { background: #fff; color: #000; font-family: var(--font-sans); }
  h1, h2, h3 { font-family: var(--font-serif); color: #000; page-break-after: avoid; }
  /* Expand links as footnotes — only external (http/https), not internal anchors */
  a[href^="http"]::after {
    content: " (" attr(href) ")";
    font-family: var(--font-mono);
    font-size: 0.85em;
    color: #444;
    word-break: break-all;
  }
  /* Hide the accent underline on h2 — irrelevant in print */
  h2::after { display: none; }
  /* Restore measure for prose readability on A4 */
  p, li { max-width: none; }
  section { break-inside: avoid-page; }
}
```

- Internal anchors (`href^="#"`) deliberately do NOT expand — they would render as `(#decouverte)`, which is noise in print.
- `<time>` elements render with their human-readable text (Phase 3 cards' `lastChecked`).
- Sticky header / burger / skip-link all `display: none`.

## Accessibility Floors (IDENT-05 + CHASSIS-04 + CHASSIS-09 + CHASSIS-10)

Hard, non-negotiable. The empty shell must pass before any content lands.

- **Contrast:** body text ≥ 4.5:1; large text and decorative ≥ 3:1. Validated via axe DevTools AND Chrome Lighthouse. Token table above is pre-validated.
- **Focus ring:** `:focus-visible` everywhere; 3 px solid `--focus-ring` (blue, intentionally non-accent so always visible); 2 px offset; rounded via `var(--radius-sm)` where appropriate.
- **Skip-link:** first focusable element in DOM; reveals on focus; jumps to `#main` and moves focus.
- **Semantic landmarks** (must all be present in Phase 1 chassis):
  - `<header role="banner">` (the role is implicit on `<header>` outside `<main>` but stated for clarity)
  - `<nav aria-label="Navigation principale">`
  - `<main id="main">`
  - `<section aria-labelledby="h-{id}">` × 4
  - `<footer role="contentinfo">`
- **`lang="fr"`** on `<html>` — content is French, locks screen-reader pronunciation.
- **`<meta name="color-scheme" content="dark light">`** in `<head>` — flags supported schemes to the browser chrome (scrollbars, form widgets).
- **`prefers-reduced-motion: reduce`** overrides smooth-scroll + transitions (see Motion Contract).
- **Touch targets:** burger label ≥ 44 × 44 px; mobile nav links ≥ 44 px tall.
- **Keyboard test (gate before phase complete):** Tab from cold load → skip-link visible first → Enter → focus in `<main>` → Tab continues through brand, burger (mobile) or nav items (desktop), then into sections; never traps; focus is always visible.
- **axe DevTools:** zero critical issues on the empty shell.
- **Lighthouse Accessibility:** ≥ 95 on the empty shell.
